# 课程映射

本 Skill 把“个人知识库到内容半自动输出”课程封装成可独立运行的工作流。购买者不需要访问原课程任务或任何私人知识库。

| 课程阶段 | Skill 动作 | 可验证产物 |
|---|---|---|
| 语料是生产资料 | `diagnose` | 资料可用性诊断、缺口清单 |
| 重建知识库架构 | `setup` / `adopt` | 固定层级、配置、起步页 |
| 从人工整理到规则驱动 | `constitution` | 人类可读章程、机器配置 |
| 从原始素材到可调用资产 | `ingest` / `review` | 四类结果、候选、台账、人工决定 |
| 从知识库到内容初稿 | `produce` | 任务单、素材包、结构、初稿 |
| 从一次输出到持续迭代 | `feedback` / `lint` | 交付台账、缺口池、过期与健康报告 |

课程核心不是全自动，而是分清责任：AI 负责重复劳动，人负责判断、晋升和最终责任。
