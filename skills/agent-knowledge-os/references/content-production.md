# 从知识库到内容初稿

内容不是从检索开始，而是从人定义任务开始。知识库提供证据，不能替代作者的命题。

## 内容任务单

依次确认，不能合并成一个模糊问题：

1. 写给谁？
2. 对方正在面对什么具体问题？
3. 本次只说清哪个核心判断？
4. 哪些话不应表达，哪些承诺不能做？
5. 使用哪些第一方经验、来源和库存知识？
6. 输出形式、长度和使用场景是什么？

## 三次人工确认

### 1. 素材包

先返回候选素材表：素材、原文位置、能支持什么、不能支持什么、置信与时效。用户删除或补充后再继续。

### 2. 结构

结构必须围绕对象的问题和核心判断，不按检索结果机械拼接。列出每部分作用和证据。

### 3. 初稿

只使用确认过的素材和边界。分清事实、用户经验、推断和建议；不把低置信来源写成确定事实。

## 验收

- 事实：能否回到来源？
- 判断：是否是作者真实同意的观点？
- 对象：读者问题是否贯穿全文？
- 表达：是否符合使用场景，是否有越界承诺？

用户稳定修改和新经验进入 feedback，不直接写成正式方法论。
